# Troubleshooting Log

Use this document to record meaningful failures and fixes encountered while building the lab.

## Entry Template

### YYYY-MM-DD — Short problem title

**Symptom**  
What failed or behaved unexpectedly?

**Cause**  
What was the actual cause, if known?

**Fix**  
What change resolved it?

**Verification**  
How was the fix confirmed?

**Lesson**  
What should be done differently next time?
